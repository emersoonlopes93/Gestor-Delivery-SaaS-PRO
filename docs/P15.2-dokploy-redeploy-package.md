## 2. Redeploy Dokploy/VPS

Sequência recomendada:

1. Garantir que o commit alvo esteja no branch que a VPS/Dokploy consome.
2. Fazer push do branch correto, se necessário.
3. Acionar redeploy pelo Dokploy.
4. Se houver risco de cache da imagem, forcar rebuild sem cache.
5. Recriar o container da API.
6. Confirmar no boot que o entrypoint iniciou somente a API.
7. Validar logs de boot e ausência de migration, limpeza, secrets ou erro de build.

### Comandos úteis na VPS

Se o deploy for por git pull + compose:

```bash
git fetch origin
git checkout <branch-correta>
git pull --ff-only
docker compose -f docker-compose.prod.yml build --no-cache api
docker compose -f docker-compose.prod.yml up -d --force-recreate api
docker compose -f docker-compose.prod.yml logs -f api
```

Se o Dokploy controlar o deploy:

- confirmar branch do serviço;
- acionar redeploy/rebuild;
- verificar logs do container novo;
- confirmar que a imagem publicada nao e antiga.
