# Checklist de aceite Go-Live

- [ ] E0-OPS concluída: API redeployada, sessões revogadas e smokes aprovados.
- [ ] DB_PASSWORD classificado e plano aprovado se aplicável.
- [ ] E0H planejada e coordenada.
- [ ] Backup recuperável, health e logs sanitizados confirmados.
- [ ] R1-R10 têm evidência autenticada ou adiamento explícito.
- [ ] Features beta/coming-soon permanecem fora do preset de produção.
- [ ] Rollback de código não restaura secrets comprometidos.
