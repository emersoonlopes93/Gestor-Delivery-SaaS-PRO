# First Paying Tenant Checklist

## Preparacao

- [ ] Backup recente confirmado.
- [ ] Restore testado.
- [ ] Plano comercial aprovado.
- [ ] Responsavel de suporte definido.
- [ ] Janela de go-live combinada com cliente.

## Criacao Do Tenant

- [ ] Criar tenant.
- [ ] Configurar plano/faixa.
- [ ] Configurar trial/grace.
- [ ] Criar usuarios do cliente.
- [ ] Revisar permissoes.

## Loja

- [ ] Configurar dados da loja.
- [ ] Configurar dominio/storefront.
- [ ] Configurar horario de funcionamento.
- [ ] Configurar catalogo minimo.
- [ ] Configurar delivery/raio/taxa.
- [ ] Configurar formas de pagamento.
- [ ] Validar imagens no CDN.

## Pedido Controlado

- [ ] Abrir storefront.
- [ ] Criar pedido teste controlado.
- [ ] Confirmar pedido no painel.
- [ ] Mover pedido ate `completed`.
- [ ] Validar revenue event.
- [ ] Validar snapshot.
- [ ] Validar invoice.

## Billing E Enforcement

- [ ] Validar assinatura ativa/trial.
- [ ] Validar suspensao em ambiente controlado.
- [ ] Validar reativacao por pagamento/acao admin.
- [ ] Validar historico de status.
- [ ] Validar acesso bloqueado quando suspenso.

## Suporte

- [ ] Testar login admin.
- [ ] Testar auditoria billing.
- [ ] Testar impersonation apenas se necessario.
- [ ] Registrar contatos de suporte.

## GO-LIVE

- [ ] Cliente aprovou storefront.
- [ ] Backup confirmado imediatamente antes.
- [ ] Monitoramento ativo.
- [ ] Plano de rollback pronto.
